# Python Notes — Learn Python by Doing

Beginner-friendly Python 3 study notes with clear explanations, code examples, quick checks, mini projects, and 20 larger projects to help you learn by writing code.

## 📘 About

**Python Notes — Learn Python by Doing** is a practical learning guide based on the official [Python 3 documentation](https://docs.python.org/3/). It is designed to help beginners build a strong foundation in Python through reading, experimenting, and hands-on practice.

The examples target **Python 3.10+**.

## ✨ What’s Included

- Beginner-friendly explanations and runnable examples
- Quick checks to test your understanding
- Mini projects throughout the chapters
- 20 larger projects that combine the concepts you learn
- A Python cheat sheet for quick revision
- An answer key for the quick checks
- Links to relevant sections of the official Python documentation

## 🚀 Getting Started

### 1. Install Python

Download Python from [python.org](https://www.python.org/downloads/). Python 3.10 or newer is recommended for the examples in this guide.

On Windows, enable **Add Python to PATH** during installation.

### 2. Download the notes

Clone this repository:

```bash
git clone <REPOSITORY_URL>
cd <REPOSITORY_FOLDER>
```

Or download the PDF directly from the repository.

### 3. Open the PDF

Open `Python_Notes_Learn_by_Doing.pdf` in your preferred PDF reader.

### 4. Practise as you learn

Type out the examples yourself, experiment with them, complete the mini projects, and then work through the 20 larger projects.

To check your Python installation, run:

```bash
python --version
```

On some systems, you may need to use:

```bash
python3 --version
```

## 🗓️ Suggested Study Plan

| Week | Chapters | Goal |
|---|---|---|
| 1 | 1–3 | Run Python and learn variables, text, decisions, and loops |
| 2 | 4–5 | Practise functions and built-in data structures |
| 3 | 6–8 | Organise code, work with files, and handle errors |
| 4 | 9–11 | Learn classes, the standard library, and virtual environments |

Aim for **30–60 minutes of practice a day**. Consistent hands-on practice is more useful than only reading the notes.
